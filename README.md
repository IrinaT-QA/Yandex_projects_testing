# My Testing Projects (Yandex.Praktikum)

Hi! This repository contains educational projects completed during the **"Software Testing Engineer"** course at Yandex.Praktikum. Here I demonstrate my skills in manual testing of web and mobile applications, API testing, working with databases, and test documentation.

---

## 1. Regression Testing of the Web Application "Mesto"

**About the project:**  
Checking the stability of an interactive image gallery (adding, liking, deleting photos) after code changes. Regression testing was performed using existing test cases, followed by retesting of previously found bugs.

**Tools:**  
- Test stand  
- Google Sheets (result recording)  
- Bug tracking (Jira)  

**Results:**  
- Core functionality confirmed to be working.  
- Unresolved bugs were identified and documented.

---

## 2. Testing the "Yandex.Routes" Feature (Validation and Calculation Logic)

**About the project:**  
Functional testing of the car trip time and cost calculation form. Verification of input field validation for addresses and time, correctness of cost and time calculations.

**Tools:**  
- Checklists, test cases  
- DevTools (request analysis)  

**Results:**  
- Defects found in validation (error messages, missing required fields).  
- Errors in cost calculation were discovered and fixed before release.

## 3. Extended Testing of Carsharing in "Yandex.Routes"

**About the project:**  
Testing the new carsharing functionality: booking form layout, logic of the "Payment Method" and "Add Card" windows, and the "Book" button.

## 4. Testing of the Mobile Application "Yandex.Metro" (Refactoring)

**About the project:**  
Testing the Android mobile application after refactoring. Functional and regression testing: offline mode, geolocation, navigation, travel time calculation.

## 5. Testing of the Yandex.Produce API

**About the project:**  
Backend testing of the Yandex.Produce service: checking the API for working with product sets, courier delivery cost calculation, and cart management (retrieve, add, delete).

**Tools:**  
- Postman (POST, GET, PUT, DELETE requests)  
- API documentation (Apidoc)  
- Google Sheets (bug reports)  

**Results:**  
- Bugs were identified: incorrect response codes, errors in delivery cost calculation, and problems with cart deletion.

---

## 6. Testing of Yandex.Scooter (Web, Mobile, API) – Diploma Project

**About the project:**  
Full cycle of testing the electric scooter rental service:  
- Web version: order form validation, order status.  
- Mobile application (Android): installation, navigation, offline scenarios.  
- API: endpoint verification via Postman and DevTools.

**Tools:**  
- Test IT (test cases, checklists)  
- Postman, DevTools, Charles Proxy  
- Android Studio (emulator)  
- Cygwin console (logs and database work)  
- Figma (mockups)  

**Results:**  
- **More than 500** test cases and checklists were created.  
- Bugs were discovered (including critical ones).  
- Regression testing was accelerated by **40%** thanks to the modular structure of checklists.
